E3SM Land Model — code explorer

Static analysis of one ELM time step (elm_drv): which routines run, which fields they read and write, and how that changes with the namelist. Pick a snapshot (an analyzed E3SM checkout) and a configuration in the toolbar; every page follows them.

Call tree

The time step as a tree of calls, pruned by the active namelist configuration, with each routine's arguments, accesses, gates and source.

Variable trace

Follow several variables through the step: which routines touch them, in what order, and when a value written is next needed.

Variable catalog

Every instance field and module variable classified as prognostic, diagnostic, intermediate, input or unused; restart/history registrations and their mismatches.

Diff mode

Compare two namelist configurations, or two snapshots: reachable routines, flipped if blocks, access sets and categories.

Types

Derived types, their members by subgrid level, instances and registrations.

Modules

Module use graph and per-module contents.
